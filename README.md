# File Sorter

Утилита для автоматической сортировки файлов по типам с графическим интерфейсом.

## Возможности

- Сортировка видео, документов, изображений, музыки и архивов
- Сканирование стандартных папок: `~/Downloads`, `~/Desktop`, `~/Documents` и др.
- Предпросмотр найденных файлов с фильтром по имени
- Параллельное перемещение файлов
- Сухой прогон (без реального перемещения)
- Добавление пользовательских папок для поиска
- Тёмная тема, кастомный заголовок окна

## Требования

- Python 3.10+
- PySide6

## Установка

```bash
pip install PySide6
```

## Запуск

```bash
python3 main.py
```

## Структура

```
├── main.py              # Точка входа
├── config.py            # Конфигурация папок и типов
├── file_utils.py        # Утилиты работы с файлами
├── extensions.json      # Расширения файлов по типам
├── gui/
│   ├── app.py           # Главное окно
│   ├── widgets/         # Виджеты (TitleBar, PreviewTable, TypeSelector и др.)
│   ├── workers/         # Фоновые воркеры
│   ├── dialogs/         # Диалоговые окна
│   └── resources/       # QSS-стили
└── requirements.txt     # Зависимости
```
